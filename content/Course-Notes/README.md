## How to Use These Notes

- **One file per lesson:** Each lesson includes class content, useful expressions, grammar explanations, and review practice.
- **Bold learning points:** Focus on the highlighted phrases when reading aloud or practising recall.
- **Edited for study:** Repeated summaries are combined, wording is polished, and misleading explanations are clarified.
- **Clear source distinctions:** Model answers and added exercises are not presented as verbatim quotations or confirmed teacher assignments.
- **Original images:** The five source images are stored in **assets/** and linked from Lesson 02; keep the folder together when moving or sharing it.

**Context note:** Lesson 01 describes listening as relatively manageable, while Lesson 02 highlights difficulties during live workplace communication; both descriptions are retained in their respective contexts.
