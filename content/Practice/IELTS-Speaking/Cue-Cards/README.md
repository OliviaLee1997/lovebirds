## Maintenance

Keep topic numbers and filenames stable. Maintain `course-order.json` alongside this index: assign each topic to its relevant course and list topics in the order covered within that course. The website orders courses from newest to oldest by default; cue-card numbers remain stable identifiers. This ordering metadata is not displayed as lesson-source labels in the study notes. Add new files as `Cue-Card-NN-Short-Topic.md` and update this index. Use the existing section structure, preserve qualifications and linking-word emphasis, and do not add navigation inside the topic files. The website generates the combined reader from these files for existing links; there is no second editable combined Markdown.
