## Maintenance

The filename number is the ordering source of truth. Keep the same number in `Cue-Card-NN-Short-Topic.md`, its `# Cue Card NN` title, and this index. Numbers follow the courses from oldest to newest. The website reads the filename number directly: newest first displays 22 down to 01, and oldest first displays 01 up to 22. Searching preserves each topic's number.

Add new topics with the next number and update this index. Use the existing section structure, preserve qualifications and linking-word emphasis, and do not add navigation inside topic files. The website generates the combined reader from these files; there is no second editable combined Markdown or separate course-order map.
