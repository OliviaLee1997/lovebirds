# English Learning by Topic — Lessons 01–19

**Scope:** A topic-based review of all 19 course lessons. There are **nine review documents**, each bringing related material together across sessions.

The original lesson files remain the chronological record. These documents provide a second way to study: choose a skill or communication task, review its patterns, and practise it with new examples. The folder-level index contains the navigation; the individual review documents begin directly with their learning content.

**Source policy:** This collection synthesises the existing edited lesson notes, including their qualifications and corrections. Model language and exercises are study material, not newly verified classroom quotations. The classification records coverage, not measured mastery or proof that every reported error was spoken by the student. Personal examples have generally been replaced with anonymous practice examples.

**How the categories fit together:** 01–05 focus on the language itself: sounds, time, sentence structure, vocabulary, and organisation. 06–09 focus on using that language in conversations, descriptions, stories, and discussions.

A topic can belong to more than one category. For example, a swimming answer uses descriptive speaking, present and past tenses, and the structure **one of my favourite sports**. This overlap is intentional.

## A Practical Review Cycle

1. Choose one category and one small section.
2. Close the notes and explain the point in your own words.
3. Write or say a new example, then compare it with the pattern.
4. Complete the review questions before reading the answers.
5. Return to the same point later and use it in a different speaking task.

**Learning checks:** Can you recognise the pattern? Explain it? Create a new example? Use it while speaking? Treat these as different achievements rather than marking a topic mastered simply because it has been read.

## Adding Later Lessons

- Keep the new lesson as its own file in the course folder.
- Add genuinely new points to the relevant topic documents and merge repeated rules into the existing explanations.
- Extend the course-to-topic map and the source lesson labels.
- Preserve distinctions between reported class content, new practice, and unresolved transcription or factual questions.
- Keep navigation in folder-level README files rather than inserting it into the lesson or topic documents.
